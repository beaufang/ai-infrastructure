# 错误处理

## 配置文件相关

| 错误 | 处理方式 |
|------|---------|
| 配置文件不存在 | 提示用户创建 `.claude/skills/rss-digest/rss-config.yaml` |
| 配置文件格式错误 | 显示具体错误信息，提示检查 YAML 格式 |

## 依赖库相关

| 错误 | 处理方式 |
|------|---------|
| `feedparser` 未安装 | 提示 `pip install feedparser pyyaml` |
| `openai` 未安装 | 提示 `pip install openai`，降级到无 AI 模式 |
| `trafilatura` 未安装 | 警告并跳过完整文章抓取，仅使用 RSS 内容 |

## RSS 源相关

| 错误 | 处理方式 |
|------|---------|
| RSS 源无法访问 | 记录错误，继续处理其他源 |
| RSS 解析失败 | 打印 bozo_exception 信息，返回空列表 |
| 某源无文章 | 跳过该源，继续处理 |

## AI 相关

| 错误 | 处理方式 |
|------|---------|
| API key 未设置 | 提示在配置文件中设置 `ai_summary.api_key`，降级到无 AI 模式 |
| AI 调用失败 | 降级到规则提取（`_rule_based_summary`） |
| 简报生成失败 | 记录错误，继续生成文件 |

## 文件相关

| 错误 | 处理方式 |
|------|---------|
| 输出目录无法创建 | 报错退出 |
| 文件写入失败 | 记录错误，继续处理下一篇 |

## 命令行参数相关

| 错误 | 处理方式 |
|------|---------|
| `--source` 指定的源不存在 | 打印可用源列表并退出 |
| `--re-summary` 未找到匹配文章 | 提示未找到，退出 |
| 日期格式错误 | 提示正确格式 `YYYY-MM-DD`，退出 |
